# Users and workflows

**DATE:** 2026-09-18

Proposed journeys to refine in feature interviews, not accepted user stories.

## Consultant working alone

Open a SketchUp model of the building. Classify the envelope faces with the assignment tool, by
face type and boundary condition. Create a material by hand, build an assembly graphically, and
assign it to faces. Create frames, glazings and a Window Type, then place window units on
the walls. Identify the thermal bridges. Author Spaces and Volumes, classify the iCFA floors,
enter ventilation rates. Validate, export HBJSON, run the METr exporter, and open the result in
METr. Save and reopen the SKP with all definitions and assignments intact. No sign-in at any step.

## Consultant reusing office work

Point the library sidebar at the firm's library file or server. Bookshelf selected definitions
and edit the copies for this building. Continue working when the library is unavailable. A
library revision does not silently change the model.

## Colleagues using shared project folders

Link a record to an existing datasheet or photo in the shared certification folder. Open the
document from the record. Each colleague maps the agreed folder on their own computer; missing
links are visible and repairable. The model remains usable when the folder is unavailable.

## Sending a model onward

Use ordinary Export for HBJSON plus the report, or the METr model. When selected evidence must
travel too, use the proposed transmission package to collect a saved model copy and its related
files.

## Contributor

Read the founding brief and the four contribution seams. Add a feature folder with one install,
a library provider that answers the provider contract, an export contributor or exporter, or a
Colour-by mode. Run the offline gate. Nothing in the core changes.

## Reviewer or certifier

Works in METr and Phius's own review tools. The reviewer does not edit the consultant's working
model through this extension.
