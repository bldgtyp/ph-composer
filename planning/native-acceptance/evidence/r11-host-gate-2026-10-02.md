## Findings, not failures

- A disabled primary button keeps its active styling (Add library file… in check 7). This is a UI-kit
  styling defect that affects any disabled primary button.
- The library export form lists raw codes, for example
  `ph_composer.windows.frame: fields_not_in_wire_schema (source)` and
  `ph_composer.windows.window_type: unsupported_kind`. Screens must show words, never codes.
- Export over an existing file asks twice (macOS, then SketchUp). It is safe but redundant.
- The library-folder confirmation from the menu says only "Done." without naming the library.
- The Frame uses bubble says "1 element uses" above four rows, one per side.
