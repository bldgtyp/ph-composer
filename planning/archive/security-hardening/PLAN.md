## Target

After SH-01 to SH-04:

- CI runs only commit-pinned actions and Dependabot proposes their bumps; the repository has a
  disclosure route and a pre-release checklist.
- The Agent Access window leads with the setup that keeps the token out of files and says where
  each form stores it; the docs say the same and name the shared-machine caveat.
- Material colours are schema-bound to six-digit hex on write and tolerated on read; every
  interpolation into report HTML passes through `ReportHtml.h`, enforced by a test; every shipped
  page declares a CSP that forbids inline scripts and network access, verified in the browser
  checks and on the proving host.
- No tracked file carries a home path, and a lint keeps it so; the bridge's state file is
  owner-only; the accepted design choices are recorded in `context/`.

## What is not in this program

- A structural fix for port squatting (F02): SH-05 records the options; the fix belongs with the
  per-connection grant packet.
- Signing or verifying the installed tree at load (F09): recorded as accepted.
- Token expiry, TLS on loopback, allowing browser-based MCP clients: accepted by design.
