# Climate data

Post-MVP. Choose the Model's climate dataset and keep a self-contained copy in the SKP with its
source. EPW-derived monthly climate supports preliminary work; METr receives climate only after
the user supplies the required peak-load cases.

Read [PRD.md](PRD.md), then [STATUS.md](STATUS.md).

In: a site location; a climate snapshot with provenance; user-owned monthly climate files;
manual entry/paste; local EPWs converted through honeybee-ph; export to honeybee-ph `Site`.
Out: any bundled or redistributed climate dataset or EPW, hosted project data, a claim that a
chosen station or EPW-derived result is certification-approved, solar analysis. EPW-derived
monthly data remains short of METr readiness until the user supplies peak-load cases.

[sun-path-view](../sun-path-view/README.md) and
[window-performance-overlays](../window-performance-overlays/README.md) depend on it.
