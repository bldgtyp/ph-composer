# Climate data

Post-MVP. Choose the Model's climate dataset, keep a self-contained copy in the SKP with its
source, and export it so METr opens with the climate already set.

Read [PRD.md](PRD.md), then [STATUS.md](STATUS.md).

In: a site location, a climate snapshot with provenance, a picker, export to honeybee-ph `Site`.
Out: any bundled Phius or PHI climate catalog without verified redistribution rights, hosted
project data, a claim that a chosen station is certification-approved, solar analysis.

[sun-path-view](../sun-path-view/README.md) and
[window-performance-overlays](../window-performance-overlays/README.md) depend on it.
