# SketchUp 2023 floor verification

Requested. Host proof that PH-Composer runs on SketchUp 2023, the declared compatibility floor.
Every host gate so far ran on SketchUp 26.1.188.

Read [PRD.md](PRD.md), then [STATUS.md](STATUS.md).

In: install, load, Overlay, HtmlDialog/Chromium, Pyodide runtime, the Phase 1 authoring and export
cases, and the measured tolerances, all on a 2023 host.
Out: Windows (see [windows-support](../windows-support/README.md)); new features.
