# Legend hover-to-highlight

Requested. Hovering a Colour-by legend row highlights that row's entities in the viewport. It is
the fourth legend affordance in the face-assignment PRD (Q18) and the only one Phase 1 did not
build, because the obvious implementation measured too slow.

Read [PRD.md](PRD.md), then [STATUS.md](STATUS.md).

In: the hover gesture on panel legend rows, a view-only highlight in the shared Colour-by overlay,
and the measurement that decides whether it ships.
Out: hover suggestions in the Classify tool (already built), table-row hover, bake-to-materials.
