# Window performance overlays

Post-MVP. Colour window units in the viewport by a performance number, with a legend and exact
values in the Window Schedule. The first metric is incident solar radiation from the Model's
monthly climate data.

Read [PRD.md](PRD.md), then [STATUS.md](STATUS.md).

In: a Colour-by mode for window units, period and ramp controls, the radiation metric.
Out: shading factors, hourly analysis, transmitted solar gain, net energy balance, any
certification claim.
