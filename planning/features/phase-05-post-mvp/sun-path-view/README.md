# Sun-path view

Post-MVP. A read-only sun path drawn in the SketchUp viewport: monthly day arcs, hourly
analemmas, a compass and a sun marker that follows SketchUp's shadow time.

Read [PRD.md](PRD.md), then [STATUS.md](STATUS.md).

In: the overlay, its placement and size, the sun marker, missing-location states.
Out: radiation or shading calculation, editable geometry, replacing SketchUp's Shadows controls.
