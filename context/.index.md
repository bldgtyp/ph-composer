# Engineering context

Durable authorities for whoever is building the extension, human or agent. A rule here outlives
the plan that produced it, and review enforces it.

| [CONTRACTS.md](CONTRACTS.md) | Core mechanics: registration, the public interface, outcomes and codes, revisions, retries, records, occurrence references, proposals and translation sections |
| [TECH_STACK.md](TECH_STACK.md) | Runtime, transactions, contribution mechanics, and the rules a later feature follows |
| [EXTENSIBILITY.md](EXTENSIBILITY.md) | Contributor architecture, scripting, metadata, extension contracts and evidence of extensibility |
| [AGENT_INTERFACE.md](AGENT_INTERFACE.md) | External-agent discovery, queries, writes, visual context and host lifecycle requirements |

| [SKETCHUP_HOST_BEHAVIOR.md](SKETCHUP_HOST_BEHAVIOR.md) | Measured host behavior and pointers to the evidence that measured it |
| [UBIQUITOUS_LANGUAGE.md](UBIQUITOUS_LANGUAGE.md) | Canonical terms and the ownership relationships between them |

Product shape, written for an outside reader, is in [`../docs/`](../docs/.index.md). The founding
brief, which records why this repository exists and what it inherits, is
